## 🔍 Возможные проблемы и решения

### 1. **n8n webhook не отвечает**
- **Решение**: Проверьте доступность вашего n8n webhook URL
- Убедитесь что авторизационный ключ корректный

### 2. **Анализ не запускается**
- **Решение**: Откройте консоль браузера (F12) и проверьте на ошибки JavaScript
- Должны быть логи: "Отправляем запрос в n8n агент:" и "Ответ от n8n агента:"

### 3. **CORS ошибки**
- **Решение**: n8n webhook должен поддерживать CORS запросы из браузера
- Попросите коллегу проверить настройки CORS в n8n

### 4. **Неожиданный формат ответа**
- **Решение**: Проверьте консоль браузера - система автоматически обрабатывает разные форматы ответов от n8n
